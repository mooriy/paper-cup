# 紙コップ水シミュレーター

紙コップの水面の揺れをブラウザーで楽しめるシミュレーターです。スマートフォンの画面を垂直にすることを想定し、左右・上下・画面に対する前後の加速度に加えて、重力センサーで検出した静止中の左右・前後の傾きにも水面が反応します。端末を傾けた状態では水面が傾き、傾きを戻すと水平に戻ります。

## 使い方

1. [GitHub Pages](https://mooriy.github.io/paper-cup/) にアクセスします。
2. iPhoneの画面を縦向きにして、端末を動かしたり、左右に傾けたりして水面の反応を確認します。
3. 「感度」のスライダーで反応の大きさを0.2x〜10.0xに調整します。初期値は1.0xです。

水がこぼれた場合は、画面をタップして水を補充できます。「リセット」は端末を垂直から30度以内に立てているときに使用でき、水量と水面が初期状態に戻ります。それ以外や姿勢を判定できない場合は、リセットボタンを押すと画面に警告が表示され、3秒後に消えます。センサーを利用できない場合は、マウスを左右に動かして操作できます。

## iPhoneでのセンサー許可

iPhoneのSafariでは、HTTPSでアクセスして画面をタップし、表示されるモーションセンサーの使用確認を許可してください。確認が表示されない場合やデータを受信できない場合は、Safariのモーションと画面の向きに関する設定を確認し、画面上のボタンから再試行してください。

このアプリは端末の加速度を使用します。利用できるセンサー情報は、端末やブラウザーの設定によって異なります。

画面下部には調査用に、重力を含む加速度の端末座標（x / y / z）、その値から算出した左右・前後の傾き、画面の向き（旧APIの値を含む）を表示します。値を取得できない場合は「未受信」または「未取得」と表示します。

## ローカルでの実行

ビルドは不要です。リポジトリのルートで静的ファイルサーバーを起動し、表示されたURLをブラウザーで開きます。例えばPythonがインストールされている場合は、次のように実行できます。

```powershell
python -m http.server 8000
```

同じコンピューターのブラウザーでは `http://localhost:8000` を開きます。スマートフォンのセンサーを使う場合は、ブラウザーが要求する安全な接続（HTTPSなど）が必要です。

## テスト

[Deno](https://deno.com/) がインストールされている環境で、リポジトリのルートから実行します。

```powershell
deno test --allow-read tests
```

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。`main` ブランチへのpush、または手動実行により、[公開ワークフロー](.github/workflows/pages.yml) がサイトをデプロイします。
